## 2. 요구사항 분석 및 실행 계획 요약

1. **환경변수 `DEFAUL_PREFIX` (및 `DEFAULT_PREFIX` 호환) 파싱 및 정규화 (`main.py`)**:
   - 환경변수 미지정 시 기본값 `"/shorturl"` 적용
   - `normalize_prefix()` 함수를 통해 선행 슬래시(`/`) 보장 및 후행 슬래시 제거 정규화 처리 (`"/"` 또는 빈 문자열일 경우 루트 `""`로 동작)
2. **하위 Subpath 기반 라우터 및 정적/문서 경로 구성**:
   - `APIRouter(prefix=BASE_PREFIX)`를 사용하여 대시보드(`{BASE_PREFIX}/`), 모든 REST API(`{BASE_PREFIX}/api/urls...`), 단축 링크(`{BASE_PREFIX}/{short_code}`)가 해당 프리픽스 하위에서 동작하도록 구성
   - Swagger(`{BASE_PREFIX}/docs`), ReDoc(`{BASE_PREFIX}/redoc`), OpenAPI(`{BASE_PREFIX}/openapi.json`), 정적 파일(`{BASE_PREFIX}/static`) 경로도 모두 `BASE_PREFIX` 하위로 마운트
   - 루트(`/`) 접속 시 `{BASE_PREFIX}/` 대시보드로 자동 리다이렉트(`307 Temporary Redirect`) 지원
3. **프론트엔드 UI 및 템플릿 네비게이션 연동 (`templates/index.html`, `templates/error.html`, `static/app.js`)**:
   - 서버 템플릿에서 `base_prefix`를 주입하고 `window.BASE_PREFIX` 전역 변수를 통해 프론트엔드의 모든 API 호출(`fetch`), 단축 URL 표시, 에러 페이지 복귀 링크, 정적 리소스 참조가 설정된 하위 subpath를 기준으로 네비게이션되도록 구현
