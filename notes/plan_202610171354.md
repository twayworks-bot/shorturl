## 1. 최소 기능 제품 (MVP: Minimum Viable Product) 정의

사용자의 핵심 요구사항을 충족하기 위해 반드시 구현되어야 하는 **MVP 핵심 범위**는 다음과 같습니다:

1. **루트 대시보드 (`GET /`) 및 하위 단축 패스 (`GET /{shorturl}`) 라우팅 분리**
   - `/` 접속 시 URL 생성 및 통합 관리 대시보드 제공
   - `/{shorturl}` 접속 시 타겟 사이트 메타정보를 보여주는 중간 랜딩 페이지 제공 (`?direct=1` 파라미터 사용 시 즉시 307 리다이렉트도 지원)
2. **타겟 사이트 메타정보 자동 추출 모듈 (`metadata_scraper.py`)**
   - 단축 링크 생성 시 타겟 URL의 HTML을 요청하여 `og:title`/`<title>`, `og:description`/`description`, `og:image`, `favicon`을 파싱하여 DB에 저장
   - 상대 경로 이미지를 절대 경로로 자동 변환하고, 접속 불가 사이트에 대해서도 기본 메타값을 생성하여 안정적으로 동작
3. **중간 랜딩 페이지 (`templates/landing.html`)**
   - 타겟 사이트의 대표 이미지(미리보기), 제목, 설명, 도메인, 원본 URL, 클릭 수, 만료일을 시각적으로 표시
   - 소셜/메신저 공유 시에도 동일한 프리뷰가 노출되도록 `<meta property="og:...">` 동적 렌더링
   - "지금 사이트로 이동" 즉시 이동 버튼과 자동 이동 카운트다운(중지/취소 토글 포함) 및 랜딩 페이지 내 메타 리프레시 기능 제공
4. **SQLite 기반 링크 매핑 및 생성 후 1년(365일) 자동 만료/소멸**
   - 링크 생성 시 만료일 미지정 시 `created_at + 365일(1년)`을 기본 만료일로 저장
   - 1년이 경과한 만료 링크는 접속 시 `410 Gone` 안내 및 대시보드 내 **[만료 링크 일괄 소멸(정리)]** 기능 제공
5. **UI 대시보드 내 링크 검색·관리 및 메타정보 강제 갱신(리프레시) 버튼**
   - 단축 코드, 원본 URL, 메타 제목/설명 통합 검색 지원
   - 각 링크 행에서 메타 미리보기(썸네일, 제목, 설명)를 표시하고 **[메타 갱신(Refresh)]** 버튼을 클릭하면 `POST /api/urls/{short_code}/refresh-meta`를 호출하여 최신 메타정보로 즉시 업데이트

## 2. 단계별 개발 세부 계획 (Implementation Plan)

### Step 1: 데이터베이스 스키마 확장 (`database.py`)
- `ShortURL` 모델에 메타데이터 컬럼 추가:
  - `meta_title` (`String(512)`, nullable=True)
  - `meta_description` (`String(2048)`, nullable=True)
  - `meta_image` (`String(2048)`, nullable=True)
  - `favicon_url` (`String(2048)`, nullable=True)
  - `meta_updated_at` (`DateTime(timezone=True)`, nullable=True)
- 기본 만료일 로직 추가: 생성 시 `expires_at`이 없으면 `datetime.now(timezone.utc) + timedelta(days=365)` 적용
- 기존 SQLite DB(`shorturl.db`)에 새 컬럼이 없을 경우 자동 마이그레이션(`ALTER TABLE`) 처리 함수 포함

### Step 2: 타겟 사이트 메타정보 파서 개발 (`metadata_scraper.py`)
- `httpx`를 사용하여 대상 URL의 HTML 헤더/바디를 안전하게 수집 (타임아웃 4초, 브라우저 User-Agent 지정)
- 정규표현식 및 HTML 메타 파싱을 통해 Open Graph (`og:title`, `og:description`, `og:image`), Twitter Card, 기본 `<title>`, `<meta name="description">`, `<link rel="icon">` 추출
- `urllib.parse.urljoin`으로 상대 경로 이미지 및 파비콘을 절대 URL로 변환

### Step 3: Pydantic 스키마 및 FastAPI 엔드포인트 고도화 (`schemas.py`, `main.py`)
- `ShortURLResponse`에 `meta_title`, `meta_description`, `meta_image`, `favicon_url`, `meta_updated_at` 필드 추가
- `POST /api/urls`:
  - `expires_at` 미입력 시 `created_at + 365일` 기본 설정
  - 생성 시 `fetch_url_metadata(original_url)` 호출하여 메타정보 저장
- `GET /api/urls`: 검색어 쿼리 파라미터(`q`) 필터링 지원
- `POST /api/urls/{short_code}/refresh-meta`:
  - 대상 사이트의 메타정보를 강제로 재수집하여 DB에 업데이트하고 갱신된 `ShortURLResponse` 반환
- `DELETE /api/urls/expired/purge`:
  - 현재 시각 기준 만료된(1년 경과 등) 링크들을 DB에서 일괄 소멸(삭제)하고 삭제 건수 반환
- `GET /{short_code}`:
  - 유효한 링크일 경우 클릭 수를 1 증가시키고, `?direct=1`이면 즉시 307 Redirect, 기본 요청이면 `templates/landing.html` 중간 랜딩 페이지를 렌더링

### Step 4: 중간 랜딩 페이지(`templates/landing.html`) 및 대시보드 UI(`templates/index.html`, `static/app.js`) 업그레이드
- `templates/landing.html` 신규 작성:
  - 타겟 사이트의 썸네일 이미지, 파비콘, 제목, 상세 설명, 원본 URL, 안전 안내 및 즉시 이동/자동 이동 카운트다운 UI 구현
- `templates/index.html` 및 `static/app.js` 업그레이드:
  - 기본 만료일 안내("미입력 시 생성 후 1년 뒤 자동 소멸") 표시
  - 목록 테이블에 타겟 사이트의 **메타 미리보기(썸네일 이미지, 제목, 설명 요약)** 표시
  - 각 항목의 관리 영역에 **[메타 갱신(리프레시)]** 버튼 추가 (클릭 시 로딩 애니메이션 및 즉시 갱신 반영)
  - 상단 검색바 및 **[만료 링크 정리]** 버튼 제공

### Step 5: 자동화 테스트(`test_main.py`) 및 검증
- 단축 링크 생성 시 기본 1년(`365일`) 만료일 자동 설정 검증
- 메타데이터 추출 및 `POST /api/urls/{short_code}/refresh-meta` 강제 갱신 동작 검증
- `GET /{short_code}` 호출 시 중간 랜딩 페이지(200 OK + 타겟 메타정보 포함) 렌더링 및 `?direct=1` 리다이렉트(307) 검증
- 만료 링크 `410 Gone` 응답 및 `DELETE /api/urls/expired/purge` 소멸 검증
